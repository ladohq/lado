# LADO 0.45.0: the release's checks

The last final is 0.44.0. The database's schema moves from 35 to 39, so 4.2, 4.4 (with
the user's own way back) and 4.6 of docs/release.md all hold. Those checks of every RC are
not repeated here; this file holds what 0.45.0 itself needs: models and model servers, the
New session window, the folder of documents, the phone, Codex in the container, and the
projects of 0.43.0 again, as the New session window changed their way in. `docker/install.sh`
and `docker/install.ps1` did not change since v0.44.0, so the installers are not run
(docs/release.md, 4.5).

- A Mac with your LADO 0.44.0 and sessions running, Docker Desktop, `uv`, `tmux`, `git`;
  a Linux machine with Docker and compose v2 (without one, note Linux as not checked).

  `ollama pull qwen3:8b`); a real LiteLLM's address and key, if at hand.

  key; a test ChatGPT account; a test GitHub account's token (`GH_TOKEN`).
